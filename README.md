# School Management System

A Django-based web application developed to manage school-related records in a simple and organized manner.

## Project Overview

The School Management System is designed to manage basic school operations such as student records, teacher details, classes, subjects, and administrative information. The project provides a structured way to store and manage school data digitally.

## Features

* Student record management
* Teacher record management
* Class and subject management
* Admin dashboard
* Digital data management
* Simple and user-friendly interface

## Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript
* SQLite3

## How to Run

Run the following commands in the project folder:
pip install django
python manage.py migrate
python manage.py runserver

Open the project in browser:

http://127.0.0.1:8000/
